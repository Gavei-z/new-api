# uniRouters Home 主页迁移说明

> 目标：将当前项目的 `/` Home 主页迁移到另一个模板项目。本文只描述 Home 页面及其公共外壳（顶部导航、页面过渡、页脚），不涉及模型页、定价页、文档页、登录注册页和 Dashboard 的页面内部。

## 1. 页面结构总览

从上到下的真实渲染顺序：

1. 固定顶部导航栏 `Navbar`
2. 首屏 Hero
3. 数据指标横幅 `StatsBanner`
4. 产品能力六宫格 `FeatureGrid`
5. 主流模型展示 `ModelShowcase`
6. 注册转化区 `CTASection`
7. 全站页脚 `Footer`

Home 页面自身只组合第 2～6 项；导航栏、页面切换动画和页脚由公共布局包裹。

## 2. 整体设计语言

- 类型：开发者工具 / AI API 平台风格的深色 SaaS 落地页。
- 页面底色：`#0a0a0f`。
- 主色：蓝色 `#3b82f6`；强调色：紫色 `#8b5cf6`；另有青色 `#06b6d4` 和翠绿色 `#10b981` 用于高光及代码语法色。
- 主文字为近白色，说明文字使用不同等级的灰紫色。
- 品牌渐变：蓝 → 紫 → 青，主要用于 Logo 背景、主按钮、品牌文字和数据数字。
- 字体：正文 `Inter` / 系统无衬线；代码和数字 `JetBrains Mono` / 等宽字体。
- 内容宽度：
  - 常规主体最大宽度约 `1280px`（Tailwind `max-w-7xl`）。
  - 指标区最大宽度约 `1152px`（`max-w-6xl`）。
  - Hero 文案最大宽度约 `896px`（`max-w-4xl`）。
  - Hero 说明和代码框约 `672px`（`max-w-2xl`）。
  - CTA 最大宽度约 `896px`（`max-w-4xl`）。
- 通用水平内边距：移动端 `16px`，`sm` 起为 `24px`。
- 常规区块上下间距：移动端 `80px`，`sm` 起 `128px`；指标区略紧凑，为 `64px / 80px`。
- 卡片多使用 16～24px 圆角、1px 暗色描边、半透明深色背景；部分叠加 `backdrop-blur`。
- 页面不使用照片或插画，视觉重点来自网格/点阵、模糊光晕、渐变文字、图标和代码窗口。

## 3. 从上到下详细说明

### 3.1 固定顶部导航栏

导航始终固定在视口顶部，层级高于正文。

内容从左到右：

- Logo：32×32px 蓝紫渐变圆角方块，内部为白色闪电图标；右侧是粗体 `uniRouters`，桌面及较宽屏幕追加小号灰色 `.api`。
- 中间导航：`模型`、`定价`、`文档`。
- 右侧操作：幽灵按钮 `登录`，蓝紫渐变主按钮 `开始使用`。

样式与状态：

- 页面位于顶部时：背景透明，上下内边距约 20px。
- 向下滚动超过 20px：上下内边距缩至约 12px，出现半透明深色玻璃背景、20px 模糊和底部分隔线；整个变化持续 300ms。
- 当前路由对应的导航项为白字和深色块背景；其他项为灰字，悬停变白并出现深色背景。
- Logo 图标有蓝色阴影，悬停时阴影增强。

移动端：

- `md` 以下隐藏中间导航和登录/注册按钮，右侧改为菜单/关闭图标。
- 打开菜单后，整屏出现黑色 60% 遮罩；右侧滑入 256px 宽玻璃侧栏。
- 侧栏从顶部留出约 96px，依次列出导航项、分隔线、登录和开始使用按钮。
- 点击遮罩或发生路由切换会关闭菜单。

动画：

- 遮罩淡入/淡出。
- 侧栏从 `x: 100%` 移到 `x: 0`，关闭时反向移动；spring 参数为 `damping: 25`、`stiffness: 200`。

4. 两个持续呼吸的模糊色球：
   - 左上偏中：256×256px，极淡蓝色。

### 3.3 数据指标横幅

这是一个横贯页面的深色半透明带，上下各有 1px 分隔线。

指标依次为：

1. `50+` — `可用模型`
2. `2.4B` — `月均请求量`
3. `15,000+` — `活跃开发者`
4. `99%` — `SLA 保障`

布局：

- 移动端为 2 列，即两行两列。
- `md` 起为 4 列单行。
- 数字居中，约 30～36px，粗体、等宽、蓝紫青渐变。
- 标签位于数字下方，为 14px 暗灰色。

动画：

- 整个网格首次进入视口时 0.6s 淡入。
- 每个数字首次进入视口后从 0 计数到目标值，持续 2s，使用指数减速 `easeOutExpo`。
- 滚动监听基于 `IntersectionObserver`，默认 threshold 0.1，底部 root margin 为 `-50px`，只执行一次。

迁移注意：当前计数函数对所有值执行 `Math.floor`，所以源码目标值虽为 `99.9`，最终显示实际是 `99%`，不是 `99.9%`。若要求视觉完全一致，应保留；若要求数据语义准确，应在迁移时单独修复。

## 4. 全局动画与交互规则

### 页面路由切换

Home 被公共 `PageTransition` 包裹：

- 进入：`opacity: 0 → 1`，`y: 12 → 0`。
- 离开：`opacity: 1 → 0`，`y: 0 → -12`。
- 时长 0.3s，`easeOut`。
- 路由层使用 `AnimatePresence mode="wait"`，即旧页面退场后新页面再入场。

### 滚动揭示

- 通过 `IntersectionObserver` 实现。
- 默认触发阈值 10%，底部提前量为 `-50px`。
- 触发后立即停止观察，因此每个元素只播放一次。
- 大部分区块使用“淡入 + 向上移动”；不同卡片通过每项 0.1s 的延迟形成阶梯效果。

### 悬停反馈

- 主按钮渐变提亮。
- 描边按钮边框和文字转蓝。
- 幽灵按钮出现暗色背景并提亮文字。
- 能力卡背景变亮，图标容器放大。
- 模型卡边框变亮并上移 4px。
- 导航 Logo 阴影加强。

### 其他全局细节

- `html` 开启平滑滚动。
- 滚动条宽/高 6px，深色轨道、灰紫色圆角滑块。
- 文本选中背景为 30% 透明蓝色。
- 未实现“减少动态效果”媒体查询；若模板项目需要无障碍适配，可迁移时补充 `prefers-reduced-motion`。

## 6. 迁移所需技术与资源

## 7. 迁移时建议确认的两个细节

1. SLA 的源码目标值为 `99.9`，但当前计数实现会向下取整，最终显示 `99%`。复制现状还是修正为 `99.9%`，需要在迁移项目中明确。
2. 模型数据和文案是静态演示数据，其中包含面向未来的模型名与价格；若模板项目接真实业务数据，建议将展示结构保留、具体内容接入目标项目的数据源。
